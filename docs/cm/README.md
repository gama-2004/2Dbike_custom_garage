# 紹介CM

`2Dカスタムガレージ_CM.mp4`(1280×720、約37秒、音なし)。発表やデモの冒頭で流す用。

| 時間 | 場面 | 字幕 |
| --- | --- | --- |
| 0〜4秒 | オープニング | そのカスタム、買う前に見てみよう。 |
| 4〜7秒 | 車種選択 | まずは、ベース車両を選んで |
| 7〜16秒 | パーツと塗装を変える(マフラー、ホイール、色) | パーツも色も、クリックひとつで ／ 合計金額や重さも、その場で計算 |
| 16〜21秒 | ネイキッド化でスクリーンが選べなくなる | 付けられない組み合わせは、自動でお知らせ |
| 21〜27秒 | 比較(並べる・重ねる) | ノーマルと並べて、違いがひと目で |
| 27〜33秒 | 保存してマイページへ | お気に入りは保存して、いつでも呼び出し |
| 33〜37秒 | エンディング | 2Dカスタムガレージ ／ R4S1 ARMY 2026年度 卒業研究 |

BGM やナレーションを付けるときは、著作権に問題のない音源(フリー素材など)を使い、動画編集ソフトで重ねる。

## 作り直し方

アプリの画面が変わったら、次の手順で録り直せる(Node.js と ffmpeg が必要)。

```
cd web
npm run build
npx vite preview --port 4173
```

別のウィンドウで:

```
node docs/cm/record-cm.cjs cm-out
ffmpeg -i cm-out/<できた .webm> -vf "fps=30,format=yuv420p,fade=t=in:st=0:d=0.5" -c:v libx264 -crf 20 cm.mp4
```
