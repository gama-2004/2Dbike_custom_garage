# 2Dカスタムガレージ

バイクを真横から見た2Dの図で、パーツや塗装を組み替えてカスタム後の見た目を確かめられるWebアプリ。卒業研究のプロジェクト。

実車を改造する前に、仕上がりのイメージと変更内容をつかめるようにすることをねらいにしている。

## 使い方

`app/index.html` をブラウザで開くだけで動く(ビルドやインストールは不要)。

GitHub Pages で公開する場合は、リポジトリの Settings → Pages で公開元のブランチを選ぶと、`https://<ユーザー名>.github.io/<リポジトリ名>/app/` で開ける。

## 現在できること

- ベース車両の選択: スーパースポーツ、アメリカンの2種(どちらもジャンルを参考にしたオリジナルデザイン)
- 部位ごとのパーツ選択、3色(メイン・サブ・ライン)の塗装とグラフィック柄
- ローダウン(車高)の調整
- プリセット(サーキット仕様、ボバー、チョッパーなど)と、ランダムな組み合わせ
- スタイル名の自動判定
- ビルドシート(部品一覧、シート高・最低地上高・車両重量の目安)
- 車体の部位クリックで設定欄へ移動
- 仕様の保存・呼び出し(ブラウザの localStorage に保存)
